📋 DESCRIPCIÓN GENERAL DEL PROYECTO
═══════════════════════════════════════════════════════════════════════════════

Desarrollar un dashboard web de análisis de datos con interfaz MINIMALISTA que:
- Lee múltiples formatos de archivos (Excel, CSV, JSON, TSV, parquet)
- Detecta automáticamente tipos de datos en cada columna
- Recomienda visualizaciones inteligentes según el contenido
- Permite seleccionar qué gráficos mostrar
- Funciona completamente en el navegador (sin servidor)
- Diseño limpio, neutral y altamente responsive

📂 FORMATOS DE ARCHIVO SOPORTADOS
═══════════════════════════════════════════════════════════════════════════════

1. Excel (.xlsx, .xls)
   - Múltiples hojas seleccionables
   - Detección de encabezados

2. CSV (.csv)
   - Auto-detección de delimitadores (coma, punto y coma, tab)
   - Encoding UTF-8, UTF-16, Latin-1
   - Manejo de comillas

3. TSV (.tsv, .txt con delimitador tab)
   - Similar a CSV pero tabulaciones

4. JSON (.json)
   - Arrays de objetos
   - Objetos anidados (aplanarlos si es posible)
   - Líneas JSON (JSONL)

5. Parquet (.parquet) - Opcional, si es posible
   - Formato binario eficiente

VALIDACIONES:
  ✓ Máximo 50MB por archivo
  ✓ Máximo 100,000 registros para visualización
  ✓ Mensaje si archivo es muy grande
  ✓ Manejo de caracteres especiales (ñ, acentos)
  ✓ Espacios en nombres de columnas

═══════════════════════════════════════════════════════════════════════════════
🔍 DETECCIÓN INTELIGENTE DE TIPOS DE DATOS
═══════════════════════════════════════════════════════════════════════════════

El sistema debe detectar automáticamente para cada columna:

TIPOS A DETECTAR:
  1. NUMÉRICO
     - Enteros, decimales, negativos, científicos
     - Estadísticas: min, max, media, mediana, desv. estándar
     - Gráficos recomendados: histograma, línea, dispersión, caja

  2. CATEGÓRICO
     - Strings, booleanos, categorías limitadas
     - Estadísticas: valores únicos, frecuencia más común, % distribución
     - Gráficos recomendados: barras, pie, donut, área apilada

  3. TEMPORAL
     - Fechas (yyyy-mm-dd, dd/mm/yyyy, etc.)
     - Horas, timestamps
     - Estadísticas: rango temporal, cantidad de períodos
     - Gráficos recomendados: línea temporal, barras temporales, calendario

  4. BOOLEANO
     - True/False, Yes/No, 1/0
     - Estadísticas: % verdadero, % falso
     - Gráficos recomendados: pie, gauge, barras

  5. TEXTO LARGO
     - Descripciones, comentarios (>50 caracteres promedio)
     - Estadísticas: largo promedio, valores únicos
     - Gráficos: nube de palabras (opcional)

  6. URL / EMAIL
     - URLs válidas, emails
     - Estadísticas: cantidad de registros válidos
     - No mostrar gráficos típicos

LÓGICA DE DETECCIÓN:
  - Escanear primeras 100 filas
  - Calcular % de valores que coinciden con tipo
  - Si >80% numérico → tipo numérico
  - Si <10 valores únicos → categórico
  - Si coincide patrón fecha → temporal
  - Etc.

📊 RECOMENDACIÓN AUTOMÁTICA DE GRÁFICOS
═══════════════════════════════════════════════════════════════════════════════

MATRIZ DE RECOMENDACIONES:

Numérico + Numérico:
  ✓ Primario: Dispersión (scatter)
  ✓ Secundario: Línea, Histograma 2D

Numérico + Categórico:
  ✓ Primario: Barras agrupadas
  ✓ Secundario: Caja (boxplot), Violín

Categórico + Categórico:
  ✓ Primario: Heatmap
  ✓ Secundario: Barras agrupadas, Burbuja

Temporal + Numérico:
  ✓ Primario: Línea temporal
  ✓ Secundario: Área, Barras temporales

Solo Numérico:
  ✓ Histograma, Densidad, Caja

Solo Categórico:
  ✓ Barras horizontales, Pie, Donut

Solo Temporal:
  ✓ Calendario heatmap, Timeline

⚙️ ESPECIFICACIONES TÉCNICAS
═══════════════════════════════════════════════════════════════════════════════

TECNOLOGÍAS RECOMENDADAS:
  • HTML5 + CSS3 + JavaScript vanilla
  • O React con CSS modules/Tailwind (minimalista)
  • Librería de gráficos: Chart.js, Plotly.js o D3.js (versión minimalista)
  • Lectura de archivos: XLSX.js, PapaParse, json-parsing nativo
  • Opcional: Apache Arrow o DuckDB.js para datasets grandes

CONSIDERACIONES DE RENDIMIENTO:
  ✓ Lazy loading de gráficos si son muchos
  ✓ Virtualizar tabla si hay >5000 registros
  ✓ Web Workers para procesamiento pesado
  ✓ Caché de cálculos

ALMACENAMIENTO:
  ✓ LocalStorage para últimas configuraciones
  ✓ Session storage para datos temporales
  ✓ No almacenar datos sensibles

🎯 COMPORTAMIENTO ESPERADO
═══════════════════════════════════════════════════════════════════════════════

1. Usuario abre la página
   → Ve header + zona de upload vacía
   → Mensaje: "Carga un archivo para comenzar"

2. Usuario carga archivo
   → Spinner de carga
   → Sistema analiza columnas (1-2 segundos)
   → Muestra panel de análisis
   → Preselectiona gráficos recomendados automáticamente

3. Usuario ve análisis
   → 3+ columnas con cards minimalistas
   → Cada card muestra: tipo, estadísticas, recomendaciones

4. Usuario ajusta gráficos
   → Toggles simples (on/off)
   → Texto pequeño describiendo cada uno
   → Botón "Aplicar cambios"

5. Dashboard se genera
   → Solo gráficos seleccionados
   → Titulo + subtítulo explicativo
   → Datos visuales claros, sin ruido
   → Tabla debajo con datos brutos

6. Usuario puede
   → Descargar gráfico como PNG
   → Descargar datos como CSV
   → Cambiar gráficos nuevamente
   → Cargar otro archivo
